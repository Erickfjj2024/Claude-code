# EstoqueFlow — Scripts GTM: Primeiros 10 Clientes Pagantes

Guia tático de prospecção sem tráfego pago. Meta: 10 clientes em 30 dias.

---

## SEMANA 1-2: Prospecção Direta (WhatsApp + LinkedIn)

### Passo a passo para mapear prospects

1. Abra o Google Maps e pesquise por setor na sua cidade:
   - "padaria [cidade]"
   - "farmácia independente [cidade]" (evite redes grandes)
   - "pet shop [cidade]"
   - "autopeças [cidade]"

2. Para cada empresa, anote em planilha:
   - Nome da empresa
   - Telefone (geralmente no perfil do Maps)
   - Nome do dono (se aparecer no Google)
   - Setor

3. Meta: 100 empresas mapeadas antes de iniciar a prospecção.

### Template WhatsApp — Primeiro Contato (Frio)

**Regra:** Nunca mande o link logo de cara. Primeiro crie contexto.

```
Olá, [Nome / "boa tarde"]! Tudo bem?

Vi que vocês têm uma [padaria/farmácia/pet shop] aqui em [cidade].
Estou desenvolvendo um sistema de controle de estoque focado em
negócios como o de vocês.

Uma pergunta rápida: vocês usam planilha, sistema ou papel pra
controlar o estoque hoje?
```

**Se responder (positivo ou negativo):**

```
Entendo! A maioria dos negócios locais que conversei usa planilha
ou caderno mesmo.

O problema é que quando o produto acaba, a gente descobre tarde
demais — já perdeu a venda.

Desenvolvi um sistema que avisa ANTES de acabar, diretamente no
celular. É gratuito por 14 dias, sem precisar de cartão.

Posso te mostrar em 10 minutos como funciona? Seria por aqui mesmo
no WhatsApp ou uma chamada rápida.
```

**Se pedir o link logo:**

```
Claro! Link de acesso: [seu-domínio]/cadastro

Mas se quiser, posso fazer o setup com você agora — leva 5 minutos
e te ajudo a importar os produtos da planilha que você já usa.
```

## Oferta de Setup Assistido (Diferencial de Conversão)

Esta é a tática mais efetiva para fechar os primeiros clientes:

### O que oferecer
- Call de 30 minutos via Google Meet ou WhatsApp
- Você entra no sistema junto com o cliente
- Cadastra os 10 primeiros produtos dele na hora
- Configura os alertas personalizados para o setor
- Ensina a registrar entrada e saída

### Por que funciona
- Remove a fricção de "não sei como usar"
- Cria relacionamento direto com o fundador
- Dá dados reais de UX para o produto
- Converte >70% dos calls em usuários ativos

### Script de call (30 min)

```
[0:00-5:00] — Contexto
"Como você controla o estoque hoje? Qual produto você mais tem
problemas de ruptura ou excesso?"

[5:00-15:00] — Setup ao vivo
Cadastrar empresa, 10 produtos principais, configurar estoques mínimos

[15:00-20:00] — Mostrar o valor
Simular uma entrada/saída e mostrar o alerta em tempo real no dashboard

[20:00-25:00] — Mostrar o resto
Relatório de valorização, histórico, como convidar funcionários

[25:00-30:00] — Fechamento natural
"Faz sentido pro seu negócio? O trial vai por mais X dias.
Se quiser continuar, o plano mais usado aqui é o de R$197/mês —
menos do que uma hora de mão de obra e evita perda de produto."
```
