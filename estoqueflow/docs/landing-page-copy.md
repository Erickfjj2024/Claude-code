## SEÇÃO 7 — FAQ

**P: É difícil de configurar?**
R: Não. Em 5 minutos você já tem os primeiros produtos cadastrados e os alertas
funcionando. Se quiser ajuda, oferecemos setup assistido gratuito por videochamada.

**P: Posso importar minha planilha de produtos?**
R: Sim. Baixe nosso template CSV, cole seus dados e faça o upload. Até 500 produtos
de uma vez.

**P: E se eu já usar um sistema de caixa (PDV)?**
R: O EstoqueFlow funciona de forma independente ou integrado via API (plano Business).
Muitos clientes usam os dois juntos sem problema.

**P: O que acontece quando o trial acaba?**
R: Você recebe um aviso 7 dias antes. Seus dados ficam salvos por 30 dias após o
vencimento, dando tempo para decidir sem perder nada.

**P: Tem aplicativo para celular?**
R: O sistema funciona no navegador do celular sem instalar nada. App nativo está
no roadmap para 2026.
